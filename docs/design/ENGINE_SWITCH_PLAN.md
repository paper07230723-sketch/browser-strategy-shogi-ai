# エンジン切り替え設計・変更計画

初版作成時の目的：水匠を利用していた既存ブラウザ将棋AIへ、つようら王11mini／11microを追加する際の安全な移行手順を定義する。  
更新日：2026年11月19日  
文書の位置付け：実施済み作業の設計履歴と、今後の切り替え時に守るべき安全要件

> **現在の状態：主要3エンジン（水匠・つようら王11mini・つようら王11micro）は動作確認済み。** この文書に記載した「水匠を最終的に削除する」という当初案は、現時点の運用方針ではない。3エンジンを利用できる状態を維持し、削除・統合は別途明確な判断がない限り行わない。

---

## 1. 当初の変更目的

既存の水匠エンジンによる対局を維持しながら、つようら王11miniおよび11microを追加し、利用者がエンジンを選択できるようにする。

当初は、評価関数の切り替えを中心とし、盤面・対局進行・WASM初期化・戦略レイヤーを必要以上に変更しない方針とした。

## 2. 変更時の基本原則

- 正常動作している水匠の実装を先に保護する。
- mini／microの互換性を確認してからアプリ本体へ統合する。
- WASM初期化方式などの大規模変更を、互換性確認前に行わない。
- エンジンの切り替えは探索・通信が停止した状態で行う。
- エンジン切り替えだけを理由に、盤面・棋譜・手番を初期化しない。
- miniとmicroの探索を同時に動かさない。
- 切り替え失敗時も対局状態を保持し、利用者が復旧できるようにする。

## 3. 当初計画した段階

### Phase 1：既存水匠の保護

既存実装をGitで保護し、エンジンJS/WASM、初期化処理、Worker/USI通信、対局状態、棋譜、設定の依存関係を確認する。mini／microの検証前に、水匠のファイルや設定を削除・上書きしない。

### Phase 2：mini／micro単体の互換性確認

アプリ統合前に、次を確認する。

- 評価データ形式と読み込み
- WASMビルド・配布ファイル
- 初期化とUSI応答
- 探索開始・停止・再探索
- 合法手の応答
- iPhone Safariでの初期化・探索
- メモリ使用量と初期化時間

互換性がない場合は、水匠を無理に変更して合わせず、別の構成を検討する。

### Phase 3：エンジン選択UI

mini／microを選べるUIを追加し、戦法指定なし／右四間飛車の各モードと組み合わせて検証する。エンジン切り替えのために右四間飛車の評価ロジックやスコア重みを変更しない。

### Phase 4：一時停止・再開

一時停止はUIを無効化するだけではなく、エンジン探索と進行中リクエストを停止する。停止中は新しい着手や局面変更を許可しない。

保持する情報：

- 現在局面
- 棋譜
- 手番
- 先手／後手の設定
- 戦型設定
- エンジン等の対局設定

再開時は同じ局面から続行する。AIの手番ならAIが再び思考し、人間の手番なら人間の着手を受け付ける。停止前の古い探索結果が後から届いても、現在局面に適用しない。

### Phase 5：停止中のエンジン切り替え

切り替えは対局が一時停止され、旧エンジンの探索・通信が完全に停止した後に限る。

1. 旧エンジンを停止する。
2. 停止応答・処理終了を確認する。
3. 必要なリソースを解放する。
4. 新エンジンを初期化する。
5. USI応答を確認する。
6. 現在局面・棋譜等を新エンジンへ設定する。
7. 初期化に成功しても自動再開せず、利用者の再開操作を待つ。

2つのエンジンを同時に探索させない。iPhone Safariのメモリ制約を考慮し、不要なWASM/Workerリソースを保持し続けない。

### Phase 6：失敗時の動作

切り替えに失敗した場合は一時停止状態を維持する。局面・棋譜・手番を保持し、分かりやすいエラーを表示する。再試行または利用可能な旧エンジンへの復旧手段を検討する。初期局面へのリセットを自動実行しない。

### Phase 7：旧エンジンの整理

当初計画ではmini／microの検証後に水匠を削除する案があった。しかし現時点では水匠も利用可能な3エンジン構成が確認されているため、この削除案は採用しない。将来エンジンを削除する場合も、明示的な方針決定・テスト・Gitによる復旧手段を確認してから実施する。

## 4. 切り替えの安全性テスト項目

- mini／micro双方で対局できる。
- エンジン切り替えを両方向で行える。
- 人間の手番で一時停止できる。
- AI思考中に一時停止できる。
- 停止中に盤面・棋譜・手番が変化しない。
- 停止中にのみエンジンを切り替えられる。
- 再開後も同じ局面・棋譜から続行する。
- AI手番ならAIが思考を再開する。
- 古い探索結果が後から適用されない。
- 切り替え失敗で局面・棋譜が失われない。
- Safariで初回起動、再起動、複数回切り替えが安定する。

## 5. 現在の扱い・変更禁止事項

現在、ユーザー報告では水匠・mini・microの3種類が動作している。従って本書は「未完了の切り替え作業指示」ではなく、導入時の設計判断と安全要件の記録として扱う。

次のUI改善（直前着手の色分け）では、エンジン初期化、USI通信、探索停止、エンジン切り替え、評価値ロジックに変更を加えない。必要が確認できない限り、対象を盤面表示に限定する。
